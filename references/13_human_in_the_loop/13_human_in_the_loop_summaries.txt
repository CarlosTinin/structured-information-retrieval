===== PAPER: 13_01_An open source machine learning framework for efficient and transparent systematic reviews =====
This paper presents ASReview, an open-source machine learning framework that accelerates the screening of titles and abstracts in systematic reviews using active learning to train classifiers that predict document relevance from limited labeled examples. The system provides flexible classifier, feature extraction, balance strategy, and query strategy components, along with a simulation mode for evaluating parameter choices across diverse reviewing applications. The authors demonstrate state-of-the-art performance while acknowledging limitations including difficulty estimating error rates and the focus on screening as only one step of the broader review process. This work is relevant to legal NLP as it provides a methodological template for human-in-the-loop document filtering pipelines, directly analogous to the multi-layer filtering approach needed to identify relevant judicial decisions from large heterogeneous legal document collections.

===== PAPER: 13_02_Deep learning based active learning technique for data annotation and improve the overall performance of classification models =====
This paper introduces DLBAL, a Deep Learning Based Active Learning framework that incrementally learns from small annotated training samples by integrating EfficientNet-B0 networks into an active learning loop for image classification. Unlike prior approaches that focus only on uncertain samples with low prediction confidence, DLBAL also leverages high-confidence instances from the unannotated set for pattern learning, assigning pseudo-labels to reduce manual annotation effort. The method achieves reasonable performance on CACD and Caltech-256 datasets with low initial error rates (1.3% and 5.5% respectively). While focused on image classification, this work is relevant to legal NLP as it demonstrates active learning strategies for reducing annotation costs that can be adapted to text classification tasks such as filtering legal document types with limited expert-labeled training data.

===== PAPER: 13_03_The state of human-centered NLP technology for fact-checking =====
This paper reviews NLP technologies for automated fact-checking with a particular focus on human-centered design, examining task formulation, dataset construction, modeling approaches, and human-in-the-loop strategies. The authors argue that practical adoption requires hybrid systems that augment rather than replace human fact-checkers, and that collaboration with stakeholders early in research is essential for technology that meets real-world needs. Key findings include that even state-of-the-art models on benchmarks like FEVER remain insufficient for practical deployment, and that human factors such as usability, intelligibility, and trust are crucial yet under-researched. This work is relevant to legal NLP as it provides a framework for designing human-AI teaming systems applicable to legal document analysis, where expert validation remains essential and full automation is neither feasible nor desirable.

===== PAPER: 13_04_Modeling and mitigating human annotation errors to design efficient stream processing systems with human-in-the-loop machine learning =====
This paper defines a framework of human annotation errors (mistakes and slips) in the context of hybrid stream processing systems, grounded in psychological theories of memory decay, and proposes an error mitigation algorithm for active learning paradigms. Drawing on cognitive psychology, the authors model how memory decay affects annotation quality over time, distinguishing between knowledge-based mistakes and attentional slips, and validate their framework through both lab-based and crowdsourcing experiments. The proposed error-avoidance sampling technique selects instances that minimize memory decay effects, improving classification performance over standard uncertainty sampling. This work is relevant to legal NLP as it addresses the critical challenge of annotation quality in human-in-the-loop systems, directly applicable to expert annotation tasks for legal document classification and NER where concept drift and annotator fatigue can degrade gold standard quality.
